# Avatars -> Angles -> Concepts Workflow

The 3-step process for turning avatar research into ready-made ad briefs.

## Step 1: Build Desire-Based Avatars

Start with the Core 5 framework (see `../avatars/README.md`). Each core avatar is anchored by one primary desire mapped to a Mass Instinct.

## Step 2: Break Into Sub-Avatars

Layer additional Core 5 categories onto each core avatar to create sub-avatars. Sub-avatars can be split across:

- **Experiences** -- different life situations sharing the same desire
- **Emotions** -- different emotional states around the same desire
- **Behaviours** -- different action patterns driven by the same desire

Each sub-avatar is more specific, more relatable, and converts at lower budget.

## Step 3: Pair Sub-Avatars With Concepts

Each **sub-avatar x concept** combination = a ready-made brief.

### Key Definitions

- **Angle** = the message and how it lands. The hook, the reason to buy, the emotional lever. One angle per ad.
- **Concept** = the delivery format. How the angle is packaged visually and structurally (e.g. whiteboard explainer, UGC testimonial, studio product graphics, lifestyle montage).

The same angle can be delivered through multiple concepts. The same concept can carry different angles. Testing both independently reveals what's working.

## Example

Given:
- Core avatar: "The Careful Parent" (desire: a clean home without worrying about what the kids touch)
- Sub-avatar: "New parent who just started reading cleaning product labels"
- Angle: "The secret to a clean kitchen you don't have to air out afterwards"
- Concept: UGC testimonial

Brief: A UGC-style video from a parent wiping down the high chair tray, showing how the product cleaned it without the harsh chemical smell. Hook plays on the label-reading worry, payoff is the relief of a clean kitchen with nothing to second-guess.

## Volume Formula

If you have 3 sub-avatars and 4 concepts, you have 12 potential briefs before you even vary the angle. This is how teams scale creative testing systematically rather than guessing.
