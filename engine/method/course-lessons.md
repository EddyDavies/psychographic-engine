# Course Lessons

The method docs in this folder are distilled from the Let It Cook course lessons. The full library lives at https://lessons.letitcook.io

It holds every video lesson, lesson page and course document. Search is semantic, and each video result links to the exact moment in the lesson where the topic is covered.

## Getting access

The site is password protected. Email Eddy for the password; you should already have his address.

## Searching from Claude Code or Codex

Once you can log in, create a search token on the lessons site and paste its setup prompt into Claude Code or Codex. That installs the `lessons-search` skill, and then you can ask things like "what do the lessons say about killing ad sets" and get answers with timestamped links.

## When to use it

- A method doc here is too brief on a point and you want the original explanation or example
- You are applying a framework (angles, 3:2:2 testing, offers, media buying) to a new brand and want to check the reasoning behind it
- An agent's answer disagrees with a method doc: check the lesson before changing either
