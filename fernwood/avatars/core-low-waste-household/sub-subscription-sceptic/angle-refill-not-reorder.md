# Angle: Refill, Don't Reorder (retired)

> Fictional worked example. Fernwood is not a real brand.
> Retired on 2026-09-01 after a strategy loss. Kept as a record; it is no longer listed in `../ranked-angles.md`. Strength is the rank it held before retirement.

**Reason to Buy:** Once the Starter Kit is set up, pods arrive before you run out, so you never have to reorder cleaning spray again.

**Emotional Lever:** Assumed at the time: the hassle of running out and reordering (Comfort). In hindsight this was the wrong lever. Profile: Implied Belief "refill brands just want to lock you in". "Arrive before you run out" describes exactly the automatic delivery she fears, so the angle violated an established belief (`engine/method/belief-framework.md`).
